# 巨潮资讯网年报批量下载实操指南

> ⚠️ **本指南保留供参考。当前 FinAgent 主数据源已切换至新浪财经（纯文本格式），详见《新浪财经年报批量下载指南.md》。**
>
> 本指南基于 2026 年 5 月实际接口验证，提供可直接运行的 Python 代码。适用于沪深 A 股上市公司年报 PDF 的自动化批量获取。

---

## 一、核心原理

巨潮资讯网（cninfo.com.cn）为公告查询页面提供了未公开的 AJAX 数据接口。该接口返回 JSON 格式的公告元数据，其中包含 PDF 文件的直接下载地址。整个流程无需登录、无需付费、无验证码，只需正确构造请求参数即可。

**流程概览：**

```
POST 查询接口 → 获取公告列表（含 adjunctUrl） → 拼接下载地址 → GET 下载 PDF
```

---

## 二、接口说明

### 2.1 查询公告列表

| 项目 | 内容 |
|------|------|
| 请求方法 | `POST` |
| URL | `http://www.cninfo.com.cn/new/hisAnnouncement/query` |
| 数据格式 | `application/x-www-form-urlencoded` |
| 响应格式 | `JSON` |

**必需请求头：**

```http
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36
Content-Type: application/x-www-form-urlencoded; charset=UTF-8
Referer: http://www.cninfo.com.cn/new/commonUrl/pageOfSearch?url=disclosure/list/search
```

**关键 POST 参数：**

| 参数名 | 必填 | 说明 |
|--------|------|------|
| `stock` | 否 | 股票查询标识，格式为 `代码,orgId`（见第三节）。留空则查询全市场 |
| `column` | 是 | 交易所标识：`sse`（上交所）/`szse`（深交所） |
| `plate` | 是 | 板块标识：`sh`（沪市主板）/`sz`（深市主板）/`szcy`（创业板）/`shkcp`（科创板） |
| `category` | 是 | 公告分类。年报固定为 `category_ndbg_szsh;` |
| `seDate` | 是 | 时间范围，格式 `YYYY-MM-DD~YYYY-MM-DD` |
| `pageNum` | 是 | 页码，从 1 开始 |
| `pageSize` | 是 | 每页条数，建议 30 |
| `isHLtitle` | 否 | 是否高亮标题关键词，建议 `true` |

### 2.2 PDF 下载地址

下载前缀固定为：

```
http://static.cninfo.com.cn/
```

完整下载地址 = 前缀 + 接口返回的 `adjunctUrl` 字段：

```python
pdf_url = f"http://static.cninfo.com.cn/{adjunct_url}"
```

**注意：** PDF 下载地址**无需任何鉴权**，可直接用浏览器或 requests 访问。

### 2.3 响应数据结构

```json
{
  "announcements": [
    {
      "secCode": "600519",               // 股票代码
      "secName": "贵州茅台",              // 公司简称
      "announcementTitle": "贵州茅台2024年年度报告",
      "announcementTime": "1743609600000", // 公告时间（毫秒时间戳）
      "adjunctUrl": "finalpage/2025-05-21/1223606780.PDF"  // PDF 相对路径
    }
  ],
  "totalRecordNum": 11060,   // 总记录数
  "totalpages": 369          // 总页数
}
```

## 三、orgId 拼接规则（关键）

这是实际操作中最容易出错的地方。`stock` 参数中的 `orgId` 不是随意填写的，而是有固定规则的机构编码：

| 板块 | 代码前缀 | orgId 拼接规则 | 示例（600519 贵州茅台） |
|------|----------|----------------|------------------------|
| **沪市主板** | 600/601/603/605 | `gssh0` + 代码 | `gssh0600519` |
| **科创板** | 688 | `gssh0` + 代码 | `gssh0688012` |
| **深市主板** | 000/001/002/003 | `gssz0` + 代码 | `gssz000001` |
| **创业板** | 300/301 | `gssz0` + 代码 | `gssz300121` |

**因此完整的 stock 参数格式为：**

```python
# 沪市
tock = "600519,gssh0600519"  # 贵州茅台
tock = "688981,gssh0688981"  # 中芯国际

# 深市
tock = "000858,gssz0000858"  # 五粮液
tock = "300750,gssz3000750"  # 宁德时代
```

如果不知道 orgId，可以通过获取 `http://www.cninfo.com.cn/new/data/sse_stock.json` 或 `sz_stock.json` 的股票清单来查找。

## 四、完整代码示例

### 4.1 单只股票年报下载

```python
import requests
import time
import re
import os
from datetime import datetime

# ========== 基础配置 ==========
QUERY_URL = "http://www.cninfo.com.cn/new/hisAnnouncement/query"
DOWNLOAD_BASE = "http://static.cninfo.com.cn/"

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36",
    "Content-Type": "application/x-www-form-urlencoded; charset=UTF-8",
    "Referer": "http://www.cninfo.com.cn/new/commonUrl/pageOfSearch?url=disclosure/list/search",
    "X-Requested-With": "XMLHttpRequest"
}

# 过滤摘要、英文版、更正修订版
EXCLUDE_PATTERN = re.compile(r'摘要|英文版|更正|修订|补充|取消')

OUTPUT_DIR = "./annual_reports"
os.makedirs(OUTPUT_DIR, exist_ok=True)


# ========== 核心函数 ==========

def get_org_id(stock_code, column):
    """根据股票代码和交易所拼接 orgId"""
    prefix = "gssh0" if column == "sse" else "gssz0"
    return f"{stock_code},{prefix}{stock_code}"


def fetch_announcements(stock_code, column, plate, start_date, end_date, page_num=1, page_size=30):
    """
    获取指定股票的年报公告列表
    
    Args:
        stock_code: 股票代码，如 "600519"
        column: "sse"(上交所) 或 "szse"(深交所)
        plate: "sh"(沪市主板)/"sz"(深市主板)/"szcy"(创业板)/"shkcp"(科创板)
        start_date: 起始日期 "YYYY-MM-DD"
        end_date: 结束日期 "YYYY-MM-DD"
        page_num: 页码
        page_size: 每页条数
    
    Returns:
        list: 公告列表（已过滤摘要/英文版）
    """
    stock_param = get_org_id(stock_code, column)
    
    params = {
        "stock": stock_param,
        "tabName": "fulltext",
        "pageNum": str(page_num),
        "pageSize": str(page_size),
        "column": column,
        "plate": plate,
        "category": "category_ndbg_szsh;",
        "seDate": f"{start_date}~{end_date}",
        "isHLtitle": "true"
    }
    
    response = requests.post(QUERY_URL, data=params, headers=HEADERS, timeout=30)
    response.raise_for_status()
    
    data = response.json()
    announcements = data.get("announcements") or []
    
    # 过滤：保留包含"年度报告"且不包含摘要/英文版/更正版的
    filtered = []
    for ann in announcements:
        title = ann.get("announcementTitle", "")
        if "年度报告" in title and not EXCLUDE_PATTERN.search(title):
            filtered.append(ann)
    
    return filtered


def download_pdf(adjunct_url, save_path):
    """
    下载 PDF 文件
    
    Args:
        adjunct_url: 接口返回的相对路径，如 "finalpage/2025-05-21/1223606780.PDF"
        save_path: 本地保存完整路径
    
    Returns:
        bool: 是否成功
        int/str: 文件大小(字节)或错误信息
    """
    pdf_url = DOWNLOAD_BASE + adjunct_url
    
    try:
        resp = requests.get(pdf_url, headers=HEADERS, timeout=120, stream=True)
        resp.raise_for_status()
        
        with open(save_path, 'wb') as f:
            for chunk in resp.iter_content(chunk_size=8192):
                f.write(chunk)
        
        file_size = os.path.getsize(save_path)
        return True, file_size
    except Exception as e:
        return False, str(e)


# ========== 使用示例 ==========

if __name__ == "__main__":
    # 示例：下载贵州茅台(600519) 2023-2025 年的年报
    stock_code = "600519"
    column = "sse"      # 上交所
    plate = "sh"        # 沪市主板
    start_date = "2023-01-01"
    end_date = "2025-05-23"
    
    print(f"正在查询 {stock_code} 的年报...")
    reports = fetch_announcements(stock_code, column, plate, start_date, end_date)
    
    print(f"找到 {len(reports)} 份年报：")
    for r in reports:
        ts = int(r["announcementTime"]) / 1000
        date_str = datetime.fromtimestamp(ts).strftime("%Y-%m-%d")
        print(f"  - {r['announcementTitle']} ({date_str})")
    
    # 下载最新一年的年报
    if reports:
        latest = reports[0]  # 接口默认按时间倒序
        safe_title = latest["announcementTitle"].replace("/", "_").replace("\\", "_")
        filename = f"{stock_code}_{safe_title}.pdf"
        filepath = os.path.join(OUTPUT_DIR, filename)
        
        print(f"\n正在下载: {latest['announcementTitle']}...")
        success, info = download_pdf(latest["adjunctUrl"], filepath)
        
        if success:
            print(f"✅ 下载成功: {filepath}")
            print(f"📊 文件大小: {info / 1024:.1f} KB ({info / 1024 / 1024:.2f} MB)")
        else:
            print(f"❌ 下载失败: {info}")
```

### 4.2 批量下载多只股票的最新年报

```python
import requests
import time
import re
import os
from datetime import datetime

QUERY_URL = "http://www.cninfo.com.cn/new/hisAnnouncement/query"
DOWNLOAD_BASE = "http://static.cninfo.com.cn/"
HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
    "Content-Type": "application/x-www-form-urlencoded; charset=UTF-8",
    "Referer": "http://www.cninfo.com.cn",
    "X-Requested-With": "XMLHttpRequest"
}
EXCLUDE_PATTERN = re.compile(r'摘要|英文版|更正|修订|补充|取消')

OUTPUT_DIR = "./annual_reports"
os.makedirs(OUTPUT_DIR, exist_ok=True)


def classify_stock(stock_code):
    """根据代码前缀自动判断 column 和 plate"""
    code = str(stock_code).strip()
    if code.startswith("60"):
        return "sse", "sh"
    elif code.startswith("68"):
        return "sse", "shkcp"
    elif code.startswith("00") or code.startswith("30"):
        return "szse", "szcy" if code.startswith("30") else "sz"
    else:
        raise ValueError(f"无法识别的代码前缀: {code}")


def download_stock_annual(stock_code, start_date="2024-01-01", end_date=None):
    """下载指定股票的最新年报 PDF"""
    end_date = end_date or datetime.now().strftime("%Y-%m-%d")
    column, plate = classify_stock(stock_code)
    
    # 拼接 orgId
    prefix = "gssh0" if column == "sse" else "gssz0"
    stock_param = f"{stock_code},{prefix}{stock_code}"
    
    params = {
        "stock": stock_param,
        "tabName": "fulltext",
        "pageNum": "1",
        "pageSize": "30",
        "column": column,
        "plate": plate,
        "category": "category_ndbg_szsh;",
        "seDate": f"{start_date}~{end_date}",
        "isHLtitle": "true"
    }
    
    resp = requests.post(QUERY_URL, data=params, headers=HEADERS, timeout=30)
    data = resp.json()
    anns = data.get("announcements") or []
    
    # 过滤并保留最新的正式年报
    filtered = [a for a in anns
                if "年度报告" in a.get("announcementTitle", "")
                and not EXCLUDE_PATTERN.search(a["announcementTitle"])]
    
    if not filtered:
        print(f"⚠️ {stock_code}: 未找到年报")
        return False
    
    # 按时间排序，取最新
    latest = max(filtered, key=lambda x: x["announcementTime"])
    
    # 下载
    pdf_url = DOWNLOAD_BASE + latest["adjunctUrl"]
    sec_name = latest.get("secName", stock_code)
    ts = int(latest["announcementTime"]) / 1000
    year = datetime.fromtimestamp(ts).year
    filename = f"{stock_code}_{sec_name}_{year}年报.pdf"
    filepath = os.path.join(OUTPUT_DIR, filename)
    
    try:
        pdf_resp = requests.get(pdf_url, headers=HEADERS, timeout=120, stream=True)
        with open(filepath, 'wb') as f:
            for chunk in pdf_resp.iter_content(8192):
                f.write(chunk)
        size_kb = os.path.getsize(filepath) / 1024
        print(f"✅ {stock_code} ({sec_name}) {year}年报: {size_kb:.0f} KB")
        return True
    except Exception as e:
        print(f"❌ {stock_code}: 下载失败 - {e}")
        return False


# ========== 批量下载示例 ==========

if __name__ == "__main__":
    # 股票代码列表
    stock_list = ["600519", "000858", "300750", "688981", "601318"]
    
    print(f"开始批量下载 {len(stock_list)} 只股票的最新年报...\n")
    
    for i, code in enumerate(stock_list):
        download_stock_annual(code)
        if i < len(stock_list) - 1:
            time.sleep(1.5)  # 间隔 1.5 秒，避免触发频率限制
    
    print(f"\n全部完成！文件保存在: {os.path.abspath(OUTPUT_DIR)}")
```

### 4.3 全市场年报扫描（用于研究/存档）

```python
import requests
import time
import re
from datetime import datetime

QUERY_URL = "http://www.cninfo.com.cn/new/hisAnnouncement/query"
HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
    "Content-Type": "application/x-www-form-urlencoded; charset=UTF-8",
    "Referer": "http://www.cninfo.com.cn"
}
EXCLUDE_PATTERN = re.compile(r'摘要|英文版|更正|修订|补充|取消')


def scan_all_annual_reports(column, plate, start_date, end_date, max_pages=None):
    """
    扫描指定市场的所有年报公告
    
    Args:
        column: "sse" 或 "szse"
        plate: "sh", "sz", "szcy", "shkcp"
        start_date: 起始日期
        end_date: 结束日期
        max_pages: 最大抓取页数，None 表示全部
    
    Yields:
        dict: 单条公告元数据
    """
    page = 1
    while True:
        params = {
            "tabName": "fulltext",
            "pageNum": str(page),
            "pageSize": "30",
            "column": column,
            "plate": plate,
            "category": "category_ndbg_szsh;",
            "seDate": f"{start_date}~{end_date}",
            "isHLtitle": "true"
        }
        
        resp = requests.post(QUERY_URL, data=params, headers=HEADERS, timeout=30)
        data = resp.json()
        anns = data.get("announcements") or []
        
        if not anns:
            break
        
        for ann in anns:
            title = ann.get("announcementTitle", "")
            if "年度报告" in title and not EXCLUDE_PATTERN.search(title):
                yield ann
        
        total_pages = data.get("totalpages", 0)
        print(f"  第 {page}/{total_pages} 页处理完成...")
        
        if max_pages and page >= max_pages:
            break
        
        page += 1
        time.sleep(1)  # 请求间隔


# 使用示例：扫描沪市主板 2024 年年报
if __name__ == "__main__":
    results = []
    for ann in scan_all_annual_reports("sse", "sh", "2024-01-01", "2024-12-31", max_pages=5):
        results.append({
            "code": ann["secCode"],
            "name": ann.get("secName", ""),
            "title": ann["announcementTitle"],
            "url": f"http://static.cninfo.com.cn/{ann['adjunctUrl']}",
            "time": ann["announcementTime"]
        })
    
    print(f"\n共扫描到 {len(results)} 份年报")
    for r in results[:10]:
        print(f"  {r['code']} {r['name']}: {r['title']}")
```

## 五、关键注意事项

### 5.1 反爬与频率控制

| 建议 | 说明 |
|------|------|
| **请求间隔** | 每次查询后 `time.sleep(1)`，批量下载时 `sleep(1.5~2)` |
| **User-Agent** | 使用常见浏览器的 User-Agent |
| **Referer** | 虽非必须，但建议添加，格式为 `http://www.cninfo.com.cn` |
| **超时设置** | 查询接口 timeout=30，PDF 下载 timeout=120（大文件） |
| **IP 限制** | 短時間内大量请求可能触发 403，可分时执行或使用代理池 |

**遇到 403 时的处理：**

```python
for attempt in range(3):
    resp = requests.post(url, data=params, headers=HEADERS, timeout=30)
    if resp.status_code == 200:
        break
    elif resp.status_code == 403:
        print(f"触发限制，等待 {attempt * 5 + 5} 秒...")
        time.sleep(attempt * 5 + 5)
```

### 5.2 年报去重与版本控制

同一公司可能发布多版本年报（初版 → 更正版 → 更新版），建议的过滤策略：

```python
# 策略1: 按代码+标题关键词去重，保留最新
from collections import defaultdict

def deduplicate_reports(announcements):
    """按股票代码分组，保留最新一版年报"""
    groups = defaultdict(list)
    for ann in announcements:
        groups[ann["secCode"]].append(ann)
    
    result = []
    for code, items in groups.items():
        # 取时间戳最大（最新）的一条
        latest = max(items, key=lambda x: x["announcementTime"])
        result.append(latest)
    
    return result

# 策略2: 严格过滤所有非原版
EXCLUDE_PATTERN = re.compile(r'摘要|英文版|更正|修订|补充|取消|更新')
# 只保留标题严格为"XXXX年年度报告"（无后缀）的
strict_pattern = re.compile(r'^\d{4}年年度报告$')  # 例如 "2024年年度报告"
```

### 5.3 摘要过滤说明

| 类型 | 标题特征 | 是否保留 | 正则匹配 |
|------|---------|---------|---------|
| 正式年报 | `2024年年度报告` | ✅ 保留 | - |
| 年报摘要 | `2024年年度报告摘要` | ❌ 过滤 | `摘要` |
| 英文版 | `2024年年度报告（英文版）` | ❌ 过滤 | `英文版` |
| 更正版 | `2024年年度报告（更正公告）` | ❌ 过滤 | `更正` |
| 修订版 | `2024年年度报告（修订版）` | ❌ 过滤 | `修订` |
| 补充版 | `关于2024年年报的补充公告` | ❌ 过滤 | `补充` |

## 六、常见问题

**Q: 接口返回 `announcements: null` 是什么原因？**

通常是因为参数错误。请检查：
- `stock` 参数是否为 `代码,orgId` 格式
- `column` 和 `plate` 是否匹配（如科创板代码用 `sse` + `shkcp`）
- `category` 参数末尾是否带了分号 `;`

**Q: 能否只获取某个行业的年报？**

接口本身不支持按行业过滤。可以先按上述方法全量获取，再用外部数据源（如 Tushare/AkShare 的行业分类表）做二次过滤。

**Q: 下载的 PDF 能否直接提取文本？**

可以。使用 `PyPDF2`、`pdfplumber` 或 `pymupdf` 等库提取：

```python
import pdfplumber

with pdfplumber.open("annual_report.pdf") as pdf:
    for page in pdf.pages:
        text = page.extract_text()
        # 处理文本...
```

## 七、替代方案速览

| 方案 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| **巨潮资讯 API（本指南）** | 需要 PDF 原文存档/分析 | 免费、直连PDF、覆盖全 | 需自行解析PDF |
| **AkShare** | 只需财务数据 | 无需处理PDF、稳定 | 无原文PDF、数据字段固定 |
| **Tushare（付费）** | 需要结构化财务数据 | 数据清洗好、接口规范 | 需积分/付费、无PDF |
| **Choice/iFind 终端** | 批量研究 | 数据完整 | 需机构账号 |

**总结：如果需要 PDF 原文用于文本分析或存档，巨潮资讯网是目前最可行的免费自动化路径；如果只需要数值化财务数据，AkShare 或 Tushare 更稳定且无需处理 PDF 解析。**
