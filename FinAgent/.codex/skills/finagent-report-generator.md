# FinAgent Report Generator Skill

## Skill Name

`finagent-report-generator`

## Description

This skill automatically generates A-share annual report research reports using the FinAgent project. It supports two analysis modes:

- **Standard Annual Analysis (`analyze`)**
  - Fetches the latest annual report PDF
  - Extracts MD&A
  - Retrieves three years of financial data
  - Generates financial signals via rule engine + LLM
  - Produces an investment director summary

- **Multi-Agent Research Report (`multi-analyze`)**
  - Extends the standard analysis with:
    - Price/volume data
    - Capital flows
    - Margin trading
    - Macro interest rates
    - Technical indicators
  - Generates a comprehensive report:
    - Markdown
    - HTML
    - Charts

## Prerequisites

1. Python 3.10+ with FinAgent installed:

   ```bash
   pip install -e .
   ```

2. `.env` file in project root containing at least:

   - `OPENAI_API_KEY`
   - RQData credentials:
     - `RQDATAC2_CONF`
     - or `RQ_USER` / `RQ_PASSWORD` / `RQ_HOST`

3. Internet access for:
   - Cninfo PDF download
   - RQData API
   - OpenAI API

## Workflow Steps

When the user requests a report, execute the following:

### 1. Parse User Request

Extract:

- Stock code (6-digit A-share code)
- As-of date (default: today)
- Analysis mode (default: `multi-analyze`)

### 2. Check Environment

Verify:

- FinAgent directory exists
- `.env` contains `OPENAI_API_KEY`

If missing, guide the user through setup.

### 3. Run Command

In the FinAgent project root:

```bash
cd /path/to/FinAgent
python -m finagent multi-analyze --stock <CODE> --as-of <DATE>
```

For standard mode:

```bash
python -m finagent analyze --stock <CODE> --as-of <DATE>
```

### 4. Monitor Output

Capture:

- stdout
- stderr

On errors, provide actionable suggestions.

Example:

- Quota exceeded → reduce `FINAGENT_MAX_WORKERS`

### 5. Present Results

Inform the user of generated output files:

- `outputs/*.md`
- `outputs/*.html`
- `outputs/*.json`
- `outputs/charts/*`

Extract and summarize key findings from generated JSON fields such as:

- `executive_summary`
- `summary`

### 6. Follow-Up

Ask whether deeper analysis is needed for:

- Inventory risk
- Cash-flow quality
- Capital structure
- Margin financing trends
- Technical signals

## Command Reference

| Mode | Command | Output |
| -------- | -------- | -------- |
| `analyze` | `python -m finagent analyze --stock 600519` | `.md` + `.json` |
| `multi-analyze` | `python -m finagent multi-analyze --stock 600519` | `.md` + `.html` + `.json` + charts |

### Optional Flags

```bash
--as-of YYYY-MM-DD
--lookback-days 500      # multi-analyze only
--output custom/path.md
```

## Environment Tuning

In `.env`:

```env
FINAGENT_MAX_WORKERS=2
OPENAI_BASE_URL=...
OPENAI_MODEL=gpt-4.1-mini
```

Notes:

- `FINAGENT_MAX_WORKERS=2`
  - Reduce worker count to avoid OpenAI rate limits

- `OPENAI_BASE_URL`
  - Use a custom API endpoint if required

- `OPENAI_MODEL`
  - Specify the desired model

## Error Handling Guide

| Error | Solution |
| --------- | --------- |
| `未在巨潮资讯找到正式年报` | Use a later `--as-of` date after annual report disclosure |
| `Quota exceeded` | Reduce `FINAGENT_MAX_WORKERS` to `1` or switch RQData account |
| `OPENAI_API_KEY is required` | Configure API key in `.env` or run in local-rules-only mode |
| Chart generation fails | Install Chinese fonts and verify the lookback period contains sufficient trading days |
