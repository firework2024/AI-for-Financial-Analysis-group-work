# 财务分析智能体知识框架提炼

## 1. 三大报表分析框架

### 1.1 资产负债表分析

资产负债表回答的问题是：企业有什么资产、靠什么资金来源支撑、资产质量是否可靠、财务结构是否安全。

重点看五件事：

- 资产结构：流动资产和非流动资产的比例，判断轻资产还是重资产
- 负债结构：流动负债、非流动负债、有息负债、经营性负债的构成
- 权益结构：未分配利润、资本公积、所有者权益变化
- 经营特征：应收账款、存货、固定资产、在建工程的变化
- 财务安全：资产质量、杠杆水平、短期流动性

资产质量分析：

- 货币资金：关注余额是否充足，是否存在受限资金，是否与利息收入匹配
- 应收账款：关注增速是否高于收入增速，坏账准备是否充分，账龄是否恶化
- 应收票据和合同资产：关注是否替代应收账款成为收入沉淀项
- 存货：关注增速是否高于收入或成本增速，是否存在积压，跌价准备是否充分
- 固定资产：关注扩张是否匹配收入增长，折旧政策是否合理
- 在建工程：关注是否长期挂账，是否及时转固，是否存在虚增资产风险
- 商誉：关注商誉规模是否过高，是否存在减值风险
- 无形资产和开发支出：关注资本化比例是否过高，摊销是否合理

营运资本分析：

- 应收账款、存货、应付账款、合同负债要组合观察
- 应收和存货快速增长会占用现金
- 应付账款增长可能说明企业占用供应商资金
- 合同负债增长通常说明预收款或订单储备增加
- 营运资本恶化会导致利润和经营现金流背离

有息负债分析：

- 短期借款
- 一年内到期的非流动负债
- 长期借款
- 应付债券
- 租赁负债

核心判断：

- 应付账款显著高于应收账款，通常说明企业在产业链中议价能力较强
- 合同负债增长，通常说明订单和下游需求较好
- 未分配利润持续积累，说明企业有较强的内生盈利能力
- 大额亏损企业常见特征是未分配利润为负，权益增长更多依赖外部融资
- 货币资金很多但同时有息负债很高，需要关注资金使用效率、资金受限或资金真实性
- 在建工程长期不转固、商誉长期不减值、存货长期高企，都是资产质量风险信号

### 1.2 利润表分析

利润表回答的问题是：企业是否赚钱、靠什么赚钱、利润是否可持续。

重点看三个层面：

- 收入规模与结构：营业收入增速、主营业务占比、收入是否持续
- 成本费用与盈利效率：营业成本、毛利率、销售费用、管理费用、研发费用、财务费用
- 利润层级与盈利质量：营业利润、利润总额、净利润、归母净利润、扣非归母净利润

收入质量分析：

- 收入增长是否伴随现金回款增长
- 收入增速是否显著高于销售商品收到的现金增速
- 收入增长是否主要沉淀为应收账款、应收票据或合同资产
- 收入是否依赖一次性项目或不可持续因素

毛利率分析：

- 毛利率上升可能来自售价提升、成本下降、产品结构改善或会计估计变化
- 毛利率下降可能来自竞争加剧、原材料涨价、产品结构恶化或产能利用率下降
- 毛利率稳定但存货跌价准备增加，可能说明盈利压力尚未完全反映在利润表中

费用率分析：

- 销售费用率 = 销售费用 / 营业收入
- 管理费用率 = 管理费用 / 营业收入
- 研发费用率 = 研发费用 / 营业收入
- 财务费用率 = 财务费用 / 营业收入

利润质量分析：

- 扣非归母净利润和归母净利润走势接近，说明利润质量较高
- 两者偏离较大，说明可能存在非经常性损益干扰
- 投资收益、公允价值变动收益、资产处置收益、政府补助等会影响利润可持续性
- 信用减值损失和资产减值损失是判断利润质量的重要项目
- 所得税有效税率异常偏低或波动较大，可能说明利润结构不稳定

核心判断：

- 收入增长但利润不增长，可能意味着成本压力、费用刚性或盈利模式尚未跑通
- 净利润增长但扣非净利润下滑，说明利润可能由非经常性损益驱动
- 毛利率下滑同时费用率上升，通常说明经营压力加大
- 利润增长但减值损失大幅增加，要关注利润是否被资产质量问题侵蚀

### 1.3 现金流量表分析

现金流量表回答的问题是：企业赚到的利润有没有变成现金，经营、投资和融资之间是否平衡。

重点看三类活动：

- 经营活动现金流：主营业务是否真正“造血”
- 投资活动现金流：扩产、研发、并购是否持续
- 筹资活动现金流：是否依赖外部融资

核心指标：

- 收现比 = 销售商品收到的现金 / 营业收入
- 净现比 = 经营活动现金流净额 / 净利润
- 自由现金流 = 经营活动现金流净额 - 资本开支
- 资本开支强度 = 购建固定资产、无形资产和其他长期资产支付的现金 / 营业收入

经营现金流结构分析：

- 经营现金流好，可能来自真实收款增加
- 经营现金流好，也可能来自压低供应商付款、应付款增加
- 经营现金流差，可能来自应收增加、存货增加或回款恶化
- 要结合应收、存货、应付一起判断现金流质量

投资现金流分析：

- 投资现金流长期为负，可能说明企业持续扩张
- 资本开支要和固定资产、在建工程、收入增长匹配
- 大额投资流出如果没有带来收入和效率改善，要关注扩张效率

筹资现金流分析：

- 筹资现金流长期为正，说明企业依赖外部资金
- 筹资现金流长期为负，可能说明企业在还债、分红或回购
- 经营现金流是否覆盖利息、短债、分红和资本开支，是判断财务安全的重要依据

核心判断：

- 收现比高，说明收入更容易转成现金
- 净现比长期高于 1，通常说明盈利质量较高
- 自由现金流持续为正，说明企业有较强的内生资金创造能力
- 成长期科技企业经营现金流和投资现金流为负并不一定异常，关键看融资是否稳定、投资是否聚焦主业
- 经营现金流长期为负、投资现金流长期为负、筹资现金流长期为正，说明企业依赖外部输血

## 2. 跨报表勾稽关系

跨报表勾稽是财务分析智能体最关键的能力之一。智能体不能只看单表，而要验证资产负债表、利润表和现金流量表之间是否自洽。

### 2.1 核心勾稽关系

1. 净利润与经营现金流

关注净利润是否能转化为经营现金流。

典型异常：

- 净利润持续为正，但经营现金流长期为负
- 净利润增长很快，但净现比持续下降
- 利润增长主要来自应收增加而不是现金回款

2. 现金流与货币资金

关注现金及现金等价物净增加额是否对应货币资金变化。

注意事项：

- 现金流量表里的现金及现金等价物不完全等于资产负债表里的货币资金
- 货币资金中可能包括受限资金、保证金、定期存款等

典型异常：

- 货币资金明显增加，但现金流量表无对应支撑
- 货币资金很多，但利息收入很低
- 货币资金很多，同时短期有息负债很高

3. 收入与应收账款、应收票据、合同资产、现金回款

关注收入增长是否带来相应现金回款，是否沉淀为债权资产。

典型异常：

- 收入增长快，但收现比低
- 应收账款、应收票据或合同资产增速高于收入增速
- 应收账款周转率下降，账龄结构恶化

4. 收入与合同负债

关注合同负债是否反映预收款和订单储备。

典型异常：

- 合同负债下降但收入没有释放
- 收入高增长但合同负债持续萎缩
- 合同负债大幅增长但后续收入没有兑现

5. 营业成本与存货

关注存货变化是否支撑营业成本和销售规模。

基本逻辑：

- 期初存货 + 本期采购或生产 - 期末存货，大体支撑营业成本

典型异常：

- 存货高增但收入和成本没有同步增长
- 存货周转率持续下降
- 毛利率稳定但存货跌价准备大幅增加

6. 资本支出、在建工程与固定资产

关注购建长期资产支付的现金是否对应在建工程和固定资产变化。

典型异常：

- 固定资产大幅增加，但投资活动现金流支出很少
- 在建工程长期挂账不转固
- 转固后折旧没有同步增加
- 资本开支很高，但固定资产周转率下降

7. 折旧摊销与固定资产、无形资产

关注折旧摊销是否与长期资产规模匹配。

典型异常：

- 固定资产规模很大，但折旧很低
- 无形资产或开发支出增长很快，但摊销不充分
- 折旧摊销政策变化导致利润被调节

8. 财务费用与有息负债

关注有息负债规模与财务费用是否匹配。

典型异常：

- 有息负债大幅增加，但财务费用没有增加
- 财务费用显著高于有息负债所能解释的水平
- 利息资本化比例异常，导致当期财务费用偏低

9. 负债变动与筹资活动

关注借款余额变化是否与取得借款、偿还债务对应。

典型异常：

- 借款余额下降，但偿还债务支付的现金很少
- 借款余额上升，但取得借款收到的现金不匹配
- 短债上升而长期债下降，债务期限结构恶化

10. 净利润、分红与所有者权益

关注净利润是否最终沉淀到未分配利润。

基本逻辑：

- 期末未分配利润 = 期初未分配利润 + 净利润 - 分红 - 其他调整

典型异常：

- 净利润很高，但未分配利润没有同步增长
- 大额分红没有在筹资现金流中体现
- 所有者权益变化无法由净利润、分红和融资解释

11. 股权融资与股本、资本公积、筹资现金流

关注股权融资是否同时反映在权益和现金流中。

典型异常：

- 股本或资本公积增加，但筹资现金流没有对应流入
- 股权融资频繁，但经营现金流长期没有改善
- 可转债转股导致权益增加，但现金流不一定增加，需要区分交易性质

12. 回购与库存股、筹资现金流

关注股份回购是否对应库存股和筹资现金流出。

典型异常：

- 库存股增加，但筹资现金流出不明显
- 回购规模较大但货币资金变化不匹配

13. 减值损失与资产账面价值

关注利润表减值是否对应资产负债表资产下降或准备增加。

典型异常：

- 资产减值损失很大，但相关资产账面价值没有明显变化
- 长期资产质量恶化，但长期不计提减值
- 存货跌价准备不足，导致资产和利润偏高

14. 所得税费用与应交税费、递延所得税

关注所得税费用、实际缴税和递延所得税是否匹配。

典型异常：

- 利润很高但所得税现金流很低
- 有效税率长期异常偏低
- 递延所得税资产持续增加但未来盈利能力不足

15. 投资收益与相关金融资产或长期股权投资

关注投资收益是否有资产基础和现金基础。

典型异常：

- 投资收益很高，但相关资产规模很小
- 投资收益大幅波动，导致净利润不可持续
- 投资收益很高但经营现金流没有改善

16. 少数股东损益与少数股东权益

关注子公司利润贡献是否与少数股东权益变化匹配。

典型异常：

- 少数股东损益占比异常高
- 归母净利润和净利润走势明显背离
- 少数股东权益变化无法由少数股东损益解释

### 2.2 间接法调整逻辑

经营活动现金流常用间接法从净利润出发调整。

主要调整项目：

- 折旧、摊销等非现金费用要加回
- 信用减值损失、资产减值损失通常要加回
- 应收账款、应收票据、合同资产增加要扣除
- 存货增加要扣除
- 预付款项增加要扣除
- 应付账款、应付票据增加要加回
- 合同负债增加通常有助于经营现金流

这套逻辑本质上是在把“权责发生制利润”还原成“真实现金流”。

### 2.3 异常识别顺序

智能体可按以下顺序排查问题：

1. 看利润和经营现金流是否断裂
2. 看收入和应收账款、应收票据、合同资产是否断裂
3. 看收入和合同负债是否匹配
4. 看营业成本和存货是否匹配
5. 看资本支出、在建工程和固定资产是否匹配
6. 看折旧摊销和长期资产是否匹配
7. 看财务费用和有息负债是否匹配
8. 看利润、分红和所有者权益是否一致
9. 看减值损失和资产账面价值是否一致
10. 看少数股东损益和少数股东权益是否一致

## 3. 财务比率分析框架

财务比率的作用，是把不同规模的公司放到可比较的尺度上。智能体不能孤立解释单个比率，应同时做横向行业比较、纵向趋势比较和多指标联动。

### 3.1 盈利能力

常用指标：

- 毛利率 = （营业收入 - 营业成本）/ 营业收入
- 营业利润率 = 营业利润 / 营业收入
- 净利率 = 净利润 / 营业收入
- 归母净利率 = 归母净利润 / 营业收入
- 扣非归母净利率 = 扣非归母净利润 / 营业收入
- 净资产收益率 ROE = 净利润 / 平均净资产
- 总资产收益率 ROA = 净利润 / 平均总资产

重点判断：

- 企业是靠高毛利赚钱，还是靠高周转赚钱
- 利润率变化来自毛利率、费用率、减值损失还是非经常性损益
- ROE 的来源是利润率、周转率，还是杠杆
- 高利润率是否能被现金流验证

### 3.2 成长能力

常用指标：

- 营收增长率
- 净利润增长率
- 归母净利润增长率
- 扣非归母净利润增长率
- 经营现金流增长率
- 总资产增长率
- 净资产增长率

重点判断：

- 增长是否可持续
- 增长是否主要来自主业
- 增长是否有现金流支撑
- 成长是否伴随财务质量恶化
- 资产扩张是否带来收入和利润扩张

### 3.3 偿债能力

短期偿债能力：

- 流动比率 = 流动资产 / 流动负债
- 速动比率 = （流动资产 - 存货）/ 流动负债
- 现金比率 = （货币资金 + 交易性金融资产）/ 流动负债
- 短债现金覆盖率 = 货币资金 / 短期有息债务

长期偿债能力：

- 资产负债率 = 总负债 / 总资产
- 产权比率 = 总负债 / 所有者权益
- 有息负债率 = 有息负债 / 总资产
- 净负债率 = 净负债 / 所有者权益
- 已获利息倍数 = （利润总额 + 利息费用）/ 利息费用
- 经营现金流债务覆盖率 = 经营活动现金流净额 / 有息负债

重点判断：

- 流动性是否紧张
- 杠杆是否过高
- 短债是否能被现金覆盖
- 利润和经营现金流是否足以覆盖利息和债务
- 企业是否具备持续偿债能力

### 3.4 经营效率

常用指标：

- 应收账款周转率 = 营业收入 / 应收账款平均余额
- 存货周转率 = 营业成本 / 存货平均余额
- 固定资产周转率 = 营业收入 / 固定资产平均净值
- 总资产周转率 = 营业收入 / 总资产平均余额

周转天数指标：

- 应收账款周转天数 = 365 / 应收账款周转率
- 存货周转天数 = 365 / 存货周转率
- 应付账款周转天数 = 365 / 应付账款周转率
- 现金转换周期 = 应收账款周转天数 + 存货周转天数 - 应付账款周转天数

重点判断：

- 资产是否高效转化为收入
- 资金回笼是否顺畅
- 库存是否积压
- 企业是否占用供应商资金
- 重资产扩张是否带来效率下降

### 3.5 现金质量

常用指标：

- 收现比 = 销售商品收到的现金 / 营业收入
- 净现比 = 经营活动现金流净额 / 净利润
- 经营现金流收入比 = 经营活动现金流净额 / 营业收入
- 经营现金流 EBITDA 比 = 经营活动现金流净额 / EBITDA
- 自由现金流净利润比 = 自由现金流 / 净利润
- 资本开支折旧摊销比 = 资本开支 / 折旧摊销

重点判断：

- 利润是否转化为现金
- 现金流是否来自真实经营，而不是延迟付款
- 企业是否有足够自由现金流支持扩张、还债和分红
- 资本开支是否过度超出折旧摊销，导致资金压力上升

## 4. 杜邦分析框架

### 4.1 传统杜邦

ROE = 销售净利率 × 总资产周转率 × 权益乘数

它回答的是三个问题：

- 赚钱能力如何
- 资产使用效率如何
- 杠杆使用程度如何

### 4.2 三种典型赚钱模式

- 高盈利型：净利率高，靠产品溢价或成本控制
- 高周转型：资产周转快，靠效率赚钱
- 高杠杆型：权益乘数高，靠负债放大 ROE

### 4.3 ROE 归因判断

ROE 上升时：

- 如果来自销售净利率提升，通常说明盈利能力改善
- 如果来自总资产周转率提升，通常说明经营效率改善
- 如果来自权益乘数提升，要警惕杠杆驱动

ROE 下降时：

- 可能来自毛利率下滑
- 可能来自费用率上升
- 可能来自资产周转变慢
- 可能来自减值损失增加
- 可能来自杠杆收缩

交叉验证：

- 高 ROE 但低净现比，说明账面回报质量不足
- 高 ROE 但高权益乘数，说明回报可能依赖杠杆
- 高 ROE 但自由现金流为负，说明扩张或营运资本占用较大

### 4.4 改进型杜邦

传统杜邦的问题是把经营性资产和金融性资产混在一起，容易误判轻资产企业的真实杠杆。

改进型杜邦更适合分析：

- 现金充裕的企业
- 轻资产企业
- 金融资产占比较高的企业

核心公式：

ROE = RNOA + (RNOA - 税后利息率) × 净财务杠杆

核心思路：

- RNOA 表示经营资产创造利润的能力
- 税后利息率表示融资成本
- 净财务杠杆表示企业使用外部资金的程度
- 当 RNOA 高于融资成本时，加杠杆提升 ROE
- 当 RNOA 低于融资成本时，加杠杆会伤害 ROE

### 4.5 杜邦分析的实战目标

智能体不能只报出 ROE 数字，还要回答：

- ROE 上升是因为什么
- ROE 下降是因为什么
- 这种变化是质量改善还是杠杆驱动
- ROE 是否能被经营现金流和自由现金流验证

## 5. 综合诊断规则

综合诊断规则用于把前面的报表分析、勾稽关系、财务比率和杜邦分析转化为可执行判断。

### 5.1 收入质量风险

典型组合：

- 高收入增长
- 低收现比
- 应收账款、应收票据或合同资产高增长
- 应收账款周转率下降

可能结论：

- 收入质量较弱
- 回款压力上升
- 可能存在放宽信用政策拉动收入的情况

### 5.2 利润质量风险

典型组合：

- 净利润增长
- 扣非净利润下滑
- 投资收益、公允价值变动收益或资产处置收益占比较高
- 经营现金流没有同步改善

可能结论：

- 利润依赖非经常性损益
- 主业盈利能力不足
- 利润可持续性偏弱

### 5.3 存货积压风险

典型组合：

- 存货增长快于收入增长
- 存货周转率下降
- 毛利率下滑
- 存货跌价准备增加

可能结论：

- 产品销售压力加大
- 库存积压风险上升
- 后续可能继续计提跌价损失

### 5.4 现金流质量风险

典型组合：

- 净利润为正
- 经营现金流为负
- 净现比持续低于 1
- 应收和存货占用资金增加

可能结论：

- 利润含金量不足
- 营运资本占用加大
- 企业需要依赖外部融资维持运营

### 5.5 杠杆型虚高 ROE

典型组合：

- ROE 较高
- 权益乘数较高
- 资产负债率较高
- 经营现金流较弱

可能结论：

- ROE 主要由杠杆放大
- 股东回报质量不高
- 财务风险较高

### 5.6 资金效率或资金真实性疑点

典型组合：

- 货币资金较高
- 有息负债也较高
- 财务费用较高
- 利息收入偏低

可能结论：

- 资金可能受限
- 资金使用效率较低
- 需要进一步核查货币资金质量

### 5.7 扩张效率风险

典型组合：

- 资本开支较高
- 在建工程或固定资产快速增长
- 固定资产周转率下降
- 收入和利润没有同步增长

可能结论：

- 扩张效率偏低
- 资产利用不足
- 后续折旧压力可能上升

### 5.8 偿债压力风险

典型组合：

- 短期有息债务较高
- 货币资金覆盖不足
- 经营现金流较弱
- 已获利息倍数下降

可能结论：

- 短期偿债压力较大
- 债务滚续依赖外部融资
- 财务安全边际下降

### 5.9 主业经营改善

典型组合：

- 收入增长
- 毛利率稳定或提升
- 费用率下降
- 扣非净利润增长
- 经营现金流同步改善

可能结论：

- 主业经营质量改善
- 规模效应开始体现
- 盈利增长可持续性较强

### 5.10 高质量 ROE 改善

典型组合：

- ROE 上升
- 销售净利率或总资产周转率提升
- 权益乘数没有明显上升
- 净现比和自由现金流改善

可能结论：

- ROE 改善来自经营质量提升
- 股东回报质量较高
- 财务风险可控
