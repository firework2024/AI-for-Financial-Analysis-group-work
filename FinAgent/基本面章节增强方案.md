# 多智能体基本面章节增强方案（完整版）

## 一、需求背景

### 现状问题
- 单纯的财务智能体（workflow.py）信息不够多元，缺少市场、资金流等上下文
- 多智能体的基本面与估值智能体（fundamental_writer）写出来的东西太幼稚，缺乏年报管理层视角

### 目标
将投资总监级别的分析能力引入多智能体模式，使基本面章节达到年报分析质量。

---

## 二、设计方案

### 2.1 核心思路

将多智能体工作流从 8 步扩展为 9 步：
1. 规划 Agent（保持不变）
2. data_executor - 获取米筐数据（保持原有职责）
3. annual_analysis_step - 年报分析与财务信号检测（新增）
4. chart_agent - 生成图表（保持原有 + 新增年报图表）
5. section_writer_agents - 各章节写作（fundamental_writer 增强）
6-9. 验证、修订、组装（保持原有流程）

### 2.2 数据流设计

Step 2b 返回的结果注入 data payload：
- annual_analysis.report: 年报元信息
- annual_analysis.mda: MD&A 提取结果
- annual_analysis.financial_data: 年报口径财务数据
- annual_analysis.financial_analysis: 财务信号分析结果
- annual_analysis.investment_director: 投资总监完整分析（8段式）
- annual_report_context: 统一格式的上下文
- pit_financials: 年报财务数据（供图表生成使用）

## 五、注意事项

### 5.1 年报下载耗时
- 年报下载 + PDF 解析约 10-30 秒
- 财务信号分析约 5-10 秒
- 投资总监分析约 10-30 秒
- 总计新增耗时约 25-70 秒

### 5.2 降级策略
- 如果年报下载失败，fundamental_writer 降级使用原有数据
- 如果投资总监分析失败，fundamental_writer 降级使用简化 prompt

### 5.3 数据格式一致性
- 无论年报分析成功与否，annual_report_context 格式保持一致
- 所有可选字段都初始化为空列表或空字符串

## 八、图表问题解决方案

### 8.1 问题描述

chart_agent 原本只读取米筐数据，生成量价、资金流、两融等图表。新增的年报分析内容（如利润驱动、现金流质量）没有对应的图表。

### 8.2 解决方案：扩展 chart_agent

思路：把年报财务数据注入 chart_agent，自动生成对应的财务图表。

#### 8.2.1 修改 run_multi_agent() 主流程

Step 2b 完成后注入年报财务数据：
data["pit_financials"] = annual_result["financial_data"]

Step 3 调用 chart_agent（自动包含年报图表）：
chart_files = chart_agent(data=data, output_dir=chart_output_dir)

#### 8.2.2 新增年报图表函数

在 chart_plots.py 中新增以下函数：

- _plot_revenue_profit_trend() - 营收/净利润多年趋势对比
- _plot_profit_vs_cashflow() - 净利润 vs 经营现金流对比
- _plot_free_cashflow() - 自由现金流趋势
- _plot_margin_roe_trend() - 毛利率/ROE 多年趋势

#### 8.2.3 在 chart_agent 中调用

pit_data = data.get("pit_financials", [])
if pit_data:
    _plot_revenue_profit_trend(pit_data, output_dir)
    _plot_profit_vs_cashflow(pit_data, output_dir)
    _plot_free_cashflow(pit_data, output_dir)
    _plot_margin_roe_trend(pit_data, output_dir)

### 8.3 修改 fundamental_writer 的 prompt

在 prompt 中添加图表与表格的分工说明：

如果 data.charts 中有对应的财务趋势图，在正文中引用。
如果没有对应图表，用 Markdown 表格代替多年数据展示。

### 8.4 最终数据流图

Step 2: data_executor
        注入: price, capital, factor, dividend, shares...

Step 2b: annual_analysis_step
        注入: annual_analysis, pit_financials

Step 3: chart_agent

        新增图表：营收/利润趋势、现金流对比、毛利率趋势...

Step 4: section_writer_agents

                 引用图表 或 用 Markdown 表格代替

## 七、fundamental_writer 的数据输入（最终版）

### 7.1 MD&A 原文不传递

原因：投资总监的分析已经包含了对 MD&A 的解读，直接用二手信息即可。

修改点：_compact_data_for_prompt() 中不传 mda_text

不传 MD&A 原文，节省约 3750 tokens。

### 7.2 估值因子、分红数据仍会提供

| 数据类型 | 来源 | fundamental_writer 会用吗 |
|----------|------|-------------------------|
| 管理层视角分析 | investment_director_analysis | 引用/重述 |
| 财务信号审核 | financial_analysis | 分析 |
| 历史财务数据 | pit_financials / metrics | 分析 |
| 当前估值因子（PE/PB/PS） | factor | 分析当前估值水平 |
| 最新分红方案 | dividend | 分析历史vs当前分红 |
| 当前股本结构 | shares | 分析当前股本 |
| MD&A 原文 | - | 不传，用二手信息 |

### 7.3 最终数据输入

fundamental_writer 接收的数据包含两部分：

**来自年报分析（新增）：**
- investment_director_analysis: 投资总监完整分析
- financial_analysis: 信号审核结果（signals, risks, metrics）

**来自米筐数据（原有，保持不变）：**
- factor: 当前估值因子
- dividend: 最新分红方案
- shares: 当前股本结构
- pit_financials: 历史财务数据

## 九、数据格式兼容性（关键问题）

### 9.1 问题根因

当前代码中存在两套 pit_financials 格式：

| 数据来源 | 格式 | 使用场景 |
|----------|------|---------|
| 米筐 fetch_financials | {"rows": [{"year": 2024, "revenue": 1200, ...}]} | build_analytical_evidence, chart_agent |
| workflow.py financial_data | [{"year": 2024, "fields": {"revenue": {"value": 1200, "source": "rqdata"}}}] | 投资总监分析 |

**如果直接覆盖 data["pit_financials"]，会导致 build_analytical_evidence 失效，其他章节写作受影响。**

### 9.2 解决方案

**不覆盖 pit_financials**，保持 _attach_stored_fundamentals 设置的值。

新增独立字段：
- data["annual_analysis"]["financial_data"] - workflow.py 格式，供投资总监分析使用
- data["annual_analysis"]["investment_director"] - 投资总监完整分析

### 9.3 数据流图（修正版）

`
Step 2: data_executor
        ├── 注入: price, capital, factor, dividend, shares...
        └── _attach_stored_fundamentals() 设置:
                data["pit_financials"] = 米筐格式
                data["annual_report_context"] = 简化版

Step 2b: annual_analysis_step
        └── 注入: data["annual_analysis"] = {
                    "financial_data": workflow格式,  # 不覆盖 pit_financials
                    "investment_director": 投资总监分析,
                    "financial_analysis": 信号审核结果,
                    ...
                }

Step 4: section_writer_agents
        └── fundamental_writer
                ├── 使用: annual_analysis（投资总监分析）
                └── 其他章节
                        └── 使用: pit_financials（米筐格式，不受影响）
`

### 9.4 关键代码修改

`python
# Step 2b 中，不要覆盖 pit_financials
data["annual_analysis"] = {
    "report": annual_result["annual_report"],
    "mda": annual_result["mda"],
    "financial_data": annual_result["financial_data"],  # workflow格式
    "financial_analysis": annual_result["financial_analysis"],
    "investment_director": annual_result["investment_director"],
}
# 重要：不设置 data["pit_financials"]，保留 _attach_stored_fundamentals 的值

# _compact_data_for_prompt 中
payload["pit_financials"] = data.get("pit_financials")  # 来自米筐，不变
payload["annual_report_context"] = data.get("annual_report_context")
`

### 9.5 不受影响的部分

- build_analytical_evidence - 继续使用米筐格式的 pit_financials
- chart_agent - 继续使用米筐格式的数据
- 其他 4 个章节 - 数据输入不变
