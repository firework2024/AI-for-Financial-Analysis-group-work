# 新浪财经年报批量下载指南（纯文本版）

> 本指南基于 2026 年 5 月实际接口验证。与巨潮资讯下载 PDF 不同，新浪财经提供的是**纯文本格式**的年报，无需 OCR 或 PDF 解析，可直接用于 NLP 分析、文本挖掘、大模型训练等场景。

---

## 一、核心原理

新浪财经为每只股票维护了一套公告系统。年报纯文本页面上，内容是**直接嵌入在 HTML 的 `<td>` 标签中**的，没有任何动态加载或反爬机制。整个流程只需要简单的 HTTP GET 请求配合 HTML 解析即可。

**流程概览：**

```
GET 年报列表页(ndbg) → 解析公告标题和id
  ↓
GET 详情页(id) → 从最大<td>中提取纯文本
  ↓
清理导航栏等杂质 → 得到可直接使用的年报正文
```

---

## 二、接口说明

### 2.1 年报列表页

| 项目 | 内容 |
|------|------|
| 请求方法 | `GET` |
| URL | `https://money.finance.sina.com.cn/corp/go.php/vCB_Bulletin/stockid/{code}/page_type/ndbg.phtml` |
| 响应编码 | **GBK**（必须用 `resp.encoding = 'gbk'`） |
| 响应格式 | HTML |

**参数说明：**

| 参数 | 位置 | 说明 |
|------|------|------|
| `code` | URL路径 | 股票代码，如 `300102`、`600519` |
| `page_type` | URL路径 | 固定为 `ndbg`（年度报告） |

**返回内容示例：**

页面中包含多条公告链接，格式如下：

```html
<a target='_blank' href='/corp/view/vCB_AllBulletinDetail.php?stockid=300102&id=12030431'>
  乾照光电：2025年年度报告
</a>
```

需要提取两个关键信息：
- `id`：公告唯一标识，如 `12030431`
- 标题文本：如 `乾照光电：2025年年度报告`

### 2.2 年报详情页（纯文本）

| 项目 | 内容 |
|------|------|
| 请求方法 | `GET` |
| URL | `https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?stockid={code}&id={公告id}` |
| 响应编码 | **GBK** |
| 响应格式 | HTML（纯文本正文在 `<td>` 标签内） |

**正文提取方法：**

详情页的正文**全部纯文本**嵌在一个 `<td>` 标签中。经实测，最有效的提取策略是：

1. 找到所有 `<td>` 标签
2. 取文本内容最长的那个（通常是唯一一个超过 10 万字符的）
3. 去掉导航栏等头部杂质，以"公司名称"或"年年度报告"作为正文起点

**同页附加信息：**

| 信息 | 提取方式 |
|------|---------|
| PDF 下载链接 | 搜索 `<a>` 标签中 `.PDF` 结尾的 `href` |
| 公告日期 | 正则匹配 `公告日期[：:]\s*(\d{4}-\d{2}-\d{2})` |

### 2.3 不同板块的 URL 规则

| 板块 | 代码前缀 | 示例 |
|------|----------|------|
| **沪市主板** | 600/601/603/605 | `600519` 贵州茅台 |
| **科创板** | 688 | `688981` 中芯国际 |
| **深市主板** | 000/001/002/003 | `000858` 五粮液 |
| **创业板** | 300/301 | `300102` 乾照光电 |

**注意：所有板块 URL 格式完全一致**，不需要像巨潮资讯那样区分 `column` 和 `plate` 参数。新浪财经只认 `stockid`。

## 三、完整代码

### 3.1 单只股票年报获取

```python
import requests
import re
from bs4 import BeautifulSoup

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36",
    "Referer": "https://money.finance.sina.com.cn"
}
EXCLUDE = re.compile(r'摘要|英文版|更正|修订')


def get_annual_report_text(stock_code, year=None):
    """
    从新浪财经获取指定股票的纯文本年报

    Parameters
    ----------
    stock_code : str
        股票代码，如 "300102", "600519"
    year : int, optional
        年报年份，如 2024。不指定则取最新年报

    Returns
    -------
    dict or None
        {
            'title': 公告标题,
            'date': 公告日期,
            'text': 纯文本内容,
            'char_count': 字符数,
            'pdf_url': PDF下载链接,
            'detail_url': 详情页URL
        }
    """
    BASE = "https://money.finance.sina.com.cn"

    # 步骤1: 获取年报列表（ndbg = 年度报告专用页面）
    list_url = f"{BASE}/corp/go.php/vCB_Bulletin/stockid/{stock_code}/page_type/ndbg.phtml"
    resp = requests.get(list_url, headers=HEADERS, timeout=30)
    resp.encoding = 'gbk'  # ★ 必须设置，否则中文乱码

    # 步骤2: 解析所有年报公告的id和标题
    pattern = re.compile(
        r"href='/corp/view/vCB_AllBulletinDetail\.php\?stockid=" + stock_code +
        r"&id=(\d+)'[^>]*>(.*?)</a>"
    )
    matches = pattern.findall(resp.text)

    # 步骤3: 筛选目标年报（过滤摘要、英文版等）
    target_id = None
    target_title = None

    for ann_id, title in matches:
        clean = re.sub(r'<[^>]+>', '', title).strip()
        if EXCLUDE.search(clean) or '年度报告' not in clean:
            continue
        if year and f'{year}年年度报告' not in clean:
            continue
        target_id = ann_id
        target_title = clean
        break

    if not target_id:
        return None

    # 步骤4: 获取详情页
    detail_url = f"{BASE}/corp/view/vCB_AllBulletinDetail.php?stockid={stock_code}&id={target_id}"
    resp2 = requests.get(detail_url, headers=HEADERS, timeout=30)
    resp2.encoding = 'gbk'

    soup = BeautifulSoup(resp2.text, 'html.parser')

    # 步骤5: 提取附加信息
    pdf_url = None
    for a in soup.find_all('a', href=True):
        if '.PDF' in a['href'] or '.pdf' in a['href']:
            pdf_url = a['href']
            if not pdf_url.startswith('http'):
                pdf_url = f"{BASE}{pdf_url}"
            break

    date_m = re.search(r'公告日期[：:]\s*(\d{4}-\d{2}-\d{2})', resp2.text)
    pub_date = date_m.group(1) if date_m else ''

    # 步骤6: 提取纯文本正文（核心：找最大的<td>）
    best_text = ""
    max_len = 0
    for td in soup.find_all('td'):
        t = td.get_text(separator='\n', strip=True)
        if len(t) > max_len:
            max_len = len(t)
            best_text = t

    # 步骤7: 清理文本（去掉导航栏等非正文内容）
    lines = best_text.split('\n')
    start = 0
    for i, line in enumerate(lines):
        if '股份有限公司' in line or '年年度报告' in line:
            start = i
            break

    # 去掉尾部免责声明等
    end = len(lines)
    for i in range(len(lines) - 1, max(start, len(lines) - 30), -1):
        if any(k in lines[i] for k in ['免责声明', '版权声明', '返回页首', '新浪简介']):
            end = i
            break

    cleaned = '\n'.join(lines[start:end]).strip()

    return {
        'title': target_title,
        'date': pub_date,
        'text': cleaned,
        'char_count': len(cleaned),
        'pdf_url': pdf_url,
        'detail_url': detail_url
    }


# ========== 使用示例 ==========
if __name__ == "__main__":
    result = get_annual_report_text("300102", year=2025)

    if result:
        print(f"标题: {result['title']}")
        print(f"日期: {result['date']}")
        print(f"字符数: {result['char_count']}")
        print(f"PDF: {result['pdf_url']}")
        print(f"\n=== 前500字 ===")
        print(result['text'][:500])

        # 保存到文件
        with open(f"{result['title']}.txt", 'w', encoding='utf-8') as f:
            f.write(result['text'])
        print(f"\n已保存到: {result['title']}.txt")
    else:
        print("未找到年报")
```

### 3.2 批量下载多只股票

```python
import requests
import re
import time
import os
from bs4 import BeautifulSoup

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
    "Referer": "https://money.finance.sina.com.cn"
}
EXCLUDE = re.compile(r'摘要|英文版|更正|修订')
OUTPUT_DIR = "./sina_annual_reports"
os.makedirs(OUTPUT_DIR, exist_ok=True)


def fetch_annual_report(stock_code, year=None):
    """获取单只股票年报纯文本，返回 (success, result_dict)"""
    BASE = "https://money.finance.sina.com.cn"

    # 获取列表
    list_url = f"{BASE}/corp/go.php/vCB_Bulletin/stockid/{stock_code}/page_type/ndbg.phtml"
    resp = requests.get(list_url, headers=HEADERS, timeout=30)
    resp.encoding = 'gbk'

    pattern = re.compile(
        r"href='/corp/view/vCB_AllBulletinDetail\.php\?stockid=" + stock_code +
        r"&id=(\d+)'[^>]*>(.*?)</a>"
    )
    matches = pattern.findall(resp.text)

    target_id = None
    target_title = None
    for ann_id, title in matches:
        clean = re.sub(r'<[^>]+>', '', title).strip()
        if EXCLUDE.search(clean) or '年度报告' not in clean:
            continue
        if year and f'{year}年年度报告' not in clean:
            continue
        target_id = ann_id
        target_title = clean
        break

    if not target_id:
        return False, {'code': stock_code, 'error': '未找到年报'}

    # 获取详情
    detail_url = f"{BASE}/corp/view/vCB_AllBulletinDetail.php?stockid={stock_code}&id={target_id}"
    resp2 = requests.get(detail_url, headers=HEADERS, timeout=30)
    resp2.encoding = 'gbk'

    soup = BeautifulSoup(resp2.text, 'html.parser')

    # 提取PDF
    pdf_url = None
    for a in soup.find_all('a', href=True):
        if '.PDF' in a['href']:
            pdf_url = a['href'] if a['href'].startswith('http') else f"{BASE}{a['href']}"
            break

    # 提取日期
    date_m = re.search(r'公告日期[：:]\s*(\d{4}-\d{2}-\d{2})', resp2.text)
    pub_date = date_m.group(1) if date_m else ''

    # 提取文本
    best_text, max_len = "", 0
    for td in soup.find_all('td'):
        t = td.get_text(separator='\n', strip=True)
        if len(t) > max_len:
            max_len = len(t)
            best_text = t

    lines = best_text.split('\n')
    start = next((i for i, l in enumerate(lines)
                  if '股份有限公司' in l or '年年度报告' in l), 0)
    end = len(lines)
    for i in range(len(lines) - 1, max(start, len(lines) - 30), -1):
        if any(k in lines[i] for k in ['免责声明', '版权声明', '返回页首']):
            end = i
            break

    cleaned = '\n'.join(lines[start:end]).strip()

    # 保存文件
    safe_title = re.sub(r'[\\/:*?"<>|]', '_', target_title)
    filepath = os.path.join(OUTPUT_DIR, f"{safe_title}.txt")
    with open(filepath, 'w', encoding='utf-8') as f:
        f.write(cleaned)

    return True, {
        'code': stock_code,
        'title': target_title,
        'date': pub_date,
        'char_count': len(cleaned),
        'pdf_url': pdf_url,
        'filepath': filepath
    }


# ========== 批量下载示例 ==========
if __name__ == "__main__":
    stocks = [
        ("600519", 2024, "贵州茅台"),
        ("300102", 2025, "乾照光电"),
        ("000858", 2024, "五粮液"),
        ("688981", 2024, "中芯国际"),
    ]

    print(f"开始批量下载 {len(stocks)} 只股票的年报...\n")

    for i, (code, year, name) in enumerate(stocks):
        print(f"[{i+1}/{len(stocks)}] {name}({code}) {year}年报 ... ", end="", flush=True)
        ok, info = fetch_annual_report(code, year=year)
        if ok:
            print(f"✅ {info['char_count']:,} 字符 → {info['filepath']}")
        else:
            print(f"❌ {info.get('error', '未知错误')}")
        if i < len(stocks) - 1:
            time.sleep(1.5)

    print(f"\n完成！文件保存在: {os.path.abspath(OUTPUT_DIR)}")
```

## 四、关键注意事项

### 4.1 编码问题（最常见）

新浪财经页面使用 **GBK 编码**。如果忘记设置 `resp.encoding = 'gbk'`，中文会全部乱码。

```python
resp = requests.get(url, headers=HEADERS, timeout=30)
resp.encoding = 'gbk'  # ← 这一行绝对不能省略
```

### 4.2 频率控制

| 建议 | 说明 |
|------|------|
| **单只股票间隔** | `time.sleep(1~1.5)` |
| **批量下载间隔** | `time.sleep(1.5~2)` |
| **单次请求超时** | 列表页 30 秒，详情页 30 秒 |
| **日请求总量** | 建议不超过 2000 只，可分多日执行 |

### 4.3 文本质量说明

新浪财经的纯文本年报有以下特点：

| 特点 | 说明 |
|------|------|
| ✅ 纯文本，无需解析 | 直接拿到可读的字符串，无格式残留 |
| ✅ 表格转为文本行 | 财务表格以行形式呈现，保留了全部数据 |
| ✅ 分页符已去除 | 连续的文本流，适合 NLP 处理 |
| ⚠️ 段落换行可能丢失 | 部分段落间没有空行，是连续文本 |
| ⚠️ 表格对齐丢失 | 原 PDF 的列对齐信息不保留 |

**适用场景：** 大模型训练、关键词检索、情感分析、文本摘要、NLP 研究

**不适用场景：** 需要精确表格对齐的财务数据分析、需要原格式排版的场景

### 4.4 过滤规则

推荐过滤以下类型的公告：

| 类型 | 标题特征 | 处理方式 |
|------|---------|---------|
| 年报摘要 | 含"摘要" | ❌ 跳过 |
| 英文版 | 含"英文版" | ❌ 跳过 |
| 更正公告 | 含"更正" | ❌ 跳过 |
| 修订版 | 含"修订" | ❌ 跳过 |
| 正式年报 | `YYYY年年度报告`（无后缀） | ✅ 保留 |

过滤正则：

```python
EXCLUDE = re.compile(r'摘要|英文版|更正|修订')
```

### 4.5 页面结构变化应对

如果未来新浪改版导致 `<td>` 提取失效，备用方案：

```python
# 备用方案：直接解析整个 body，找最长的文本块
body = soup.find('body')
if body:
    text = body.get_text(separator='\n', strip=True)
    # 然后通过正则或关键词定位正文起止位置
```

## 五、常见问题

**Q: 编码设置后还是乱码怎么办？**

尝试用 `resp.apparent_encoding` 自动检测，或强制 GB18030：

```python
resp.encoding = resp.apparent_encoding  # 自动检测
# 或
resp.encoding = 'gb18030'  # GB18030 兼容更多生僻字
```

**Q: 详情页文本提取为空？**

检查 `<td>` 标签的搜索策略。如果页面改版，尝试：

```python
# 备用：查找所有可能包含正文的容器
for tag in soup.find_all(['td', 'div']):
    text = tag.get_text(strip=True)
    if len(text) > 50000:  # 年报通常超过 5 万字符
        print(f"找到正文容器: <{tag.name}> class={tag.get('class')} id={tag.get('id')}")
```

**Q: 能否获取历史年份的年报？**

可以。年报列表页 `ndbg` 会返回该股票**所有历史年报**，按时间倒序排列。通过指定 `year` 参数或遍历列表即可获取任意年份。

**Q: 文本中的财务数据是否完整？**

完整。新浪财经的纯文本包含了年报全文，包括所有财务报表数据。只是表格格式变成了文本行，数据本身没有丢失。

**Q: 可以同时下载 PDF 吗？**

可以。详情页中同时提供了 PDF 下载链接（见 `pdf_url` 字段），可一并保存：

```python
pdf_resp = requests.get(pdf_url, headers=HEADERS, timeout=120, stream=True)
with open("report.pdf", 'wb') as f:
    for chunk in pdf_resp.iter_content(8192):
        f.write(chunk)
```

## 六、方案对比：新浪财经 vs 巨潮资讯

| 对比项 | 新浪财经（本指南） | 巨潮资讯 |
|--------|-------------------|---------|
| **输出格式** | 纯文本 | PDF 文件 |
| **是否需要解析 PDF** | ❌ 不需要 | ✅ 需要（PyPDF2/pdfplumber） |
| **文本质量** | 直接可用，无需后处理 | 需 OCR 或 PDF 解析，可能丢格式 |
| **适用场景** | NLP、大模型训练、文本分析 | 需要原版式存档、精确表格分析 |
| **接口稳定性** | 较高（简单 HTML） | 较高（JSON API） |
| **编码处理** | 需手动设置 GBK | UTF-8，无需处理 |
| **股票覆盖** | 沪深 A 股全量 | 沪深京 A 股全量 |
| **请求复杂度** | GET 请求 + HTML 解析 | POST 请求 + JSON 解析 + orgId 拼接 |
| **频率限制** | 较宽松 | 有 IP 频率限制 |

**建议：**

- **做 NLP / 文本挖掘 / 大模型训练** → 用新浪财经（纯文本，直接喂给模型）
- **需要 PDF 存档 / 精确财务表格** → 用巨潮资讯（PDF 保留原格式）
- **两者结合** → 新浪财经取文本做分析，巨潮资讯下载 PDF 做备份
